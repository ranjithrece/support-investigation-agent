# Clarification
Ask ONLY when a missing fact would change the resolution (which product/service, exact error, scope of impact, when it started, what the user already tried).
- Ask exactly **one** question, specific and answerable in one sentence.
- Do not ask for information already in the ticket, the customer memory, or earlier answers.
- Never ask for passwords, tokens or other secrets.
- If the user already answered once and evidence is still thin, prefer resolving with caveats or escalating over asking again.
